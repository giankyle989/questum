# Questum brand assets

Source files for Questum's brand identity. Runtime app images live in `../images/`; this folder is for design source files that get exported into product assets.

## Files

- `app-icon.svg` — primary app icon. Solid gold hex (`#E8C547`) on deep navy (`#0E1116`) background, with a Manrope ExtraBold "Q" cut out in the same dark navy as the background, geometrically centered. 1024×1024 viewBox. The dark Q is rendered using the background color (not transparent) so the icon stays a single sealed shape — iOS adds the squircle mask automatically.
- `wordmark.svg` — primary wordmark. "QUESTUM" caps lockup in Manrope ExtraBold (`#E6EDF3`) over a "Level up real life" kicker in Manrope Semibold (`#E8C547`). The SVG references Manrope via Google Fonts at render time.

## Mascot vs. icon

These are two different jobs:

- **App icon** (`app-icon.svg`) is what users see at 60×60px on a home screen. Single shape, single accent color, no detail. Reads in a fraction of a second.
- **Mascot** (`../images/mascot-*.png`) is the chibi character — used for splash screens, onboarding heroes, empty states, social posts, screenshots. Carries personality. Lives at larger sizes where its detail is an asset.

Don't conflate them. The mascot is not the app icon and never will be.

## Production export workflow

The `wordmark.svg` references Manrope via the Google Fonts CDN and renders correctly in any browser with internet access. For production exports (App Store screenshots, splash, social images), convert the text to outlines so the file is self-contained:

1. Install Manrope locally: <https://fonts.google.com/specimen/Manrope> (need weights 600 and 800)
2. Open `wordmark.svg` in Figma, Illustrator, Inkscape, or similar
3. Convert text to outlines / paths (Figma: ⌘⇧O · Illustrator: ⌘⇧O · Inkscape: Path → Object to Path)
4. Export as PNG at the size you need

## Why typography is not generated by Gemini

Image generators consistently hallucinate letterforms — kerning drifts, characters morph, the "Q" tail mutates. Wordmarks are deterministic typography, not a generative task. Always render the wordmark from the SVG.
